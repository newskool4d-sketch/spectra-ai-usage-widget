# SPECTRA v0.2.8 작업표시줄 유지 모듈

볼륨·빠른 설정 메뉴를 열었다 닫은 뒤에도 SPECTRA 숫자가 보이도록, 확인된 v0.2.8 앱에 외부 유지 모듈을 연결합니다. Windows 로그인 때 앱과 유지 모듈을 자동 실행합니다.

앱 실행 파일, 계정 정보와 환경설정은 교체하지 않습니다. 이 파일은 기존 v0.2.8 설치 파일에 추가로 적용하는 배포물이며 앱의 자동 업데이트에는 포함되지 않습니다.

## 설치

Windows x64, SPECTRA v0.2.8, PowerShell 7이 필요합니다. 이 모듈은 SHA-256이 `A67DC7BA19B5F245EC23C8450899093438F5DDCDF2A7E8FEA982A7F2007C8C20`인 확인된 앱 실행 파일에만 적용됩니다.

1. 릴리스의 `SPECTRA_0.2.8_taskbar-keeper.zip`을 다운로드하고 압축을 풉니다.
2. 압축을 푼 폴더에서 다음 명령을 실행합니다.

```powershell
pwsh -NoProfile -ExecutionPolicy Bypass -File .\install-taskbar-keeper.ps1
```

현재 사용자용 `SPECTRA Taskbar Keeper` 작업을 등록하며 관리자 권한이나 비밀번호 저장은 필요하지 않습니다. 기존 작업 또는 유지 모듈 폴더가 있으면 덮어쓰지 않고 중단합니다. 이미 유지 모듈을 적용한 PC에서는 다시 설치할 필요가 없습니다.

## 실행

로그인 시 앱이 실행 중이면 그대로 유지하고, 없으면 설치된 앱을 시작합니다. 사용자가 앱을 종료하면 유지 모듈은 다음 앱 실행을 기다립니다. 현재 세션에서 앱을 강제로 다시 켜지는 않습니다.

유지 모듈은 `%LOCALAPPDATA%\SPECTRA\taskbar-keeper`에 설치됩니다. Windows 작업 스케줄러에서 `SPECTRA Taskbar Keeper`를 사용 안 함으로 바꾸면 다음 로그인부터 자동 실행을 중단할 수 있습니다.

## 검증 범위

현재 PC에서 볼륨 메뉴를 닫은 뒤 숫자가 계속 보이는 것을 사용자에게 확인받았습니다. 로그인 트리거 등록, 실제 작업 실행, 기존 앱 프로세스 유지와 파일 해시 보존을 확인했습니다. 실제 재부팅, 다른 PC의 새 설치는 아직 검증하지 않았습니다.

이 배포물은 현재 성공한 외부 유지 방식입니다. 앱 내부 수정으로 해결됐다고 주장하지 않습니다.
