# SPECTRA 디자인 기준선 1

2026년 8월 15일에 데스크톱 A와 모바일 C를 제품 방향으로 확정했습니다. 이 폴더의 코드·결정문·스크린샷이 디자인 원본이며 Figma 파일은 실행, 검수, 제품화에 필요하지 않습니다.

공용 스타일 값은 [`styles/tokens.css`](../../styles/tokens.css)에 모았습니다. 화면별 CSS는 이 토큰을 사용하고, 새 색상이나 유리 표면을 직접 추가하지 않습니다.

## 선택한 구조

- 데스크톱은 A의 한눈에 보기 구조를 사용합니다. 전체 사용 여유, 실시간 사용, 서비스별 현황, 집중 확인, 월 예상 비용, 알림을 한 화면에 둡니다.
- 모바일과 iOS 위젯은 C의 알림 중심 구조를 사용합니다. 전체 여유를 먼저 보여 주고, 확인이 필요한 항목을 시간순으로 배치합니다.
- C 오른쪽의 기기별 미리보기는 맥·Windows·iOS가 같은 데이터를 공유한다는 제품 원칙을 설명하는 참고 화면입니다.
- B와 화면 아래 시안 전환 막대는 실험 기록입니다. 실제 제품 UI에는 넣지 않습니다.

## 디자인 원칙

- 한글은 Pretendard를 우선 사용하고 운영체제 한글 글꼴로 자연스럽게 대체합니다.
- 영문 슬로건, 넓은 대문자 자간, 네온 후광은 사용하지 않습니다.
- 청록·테라코타·보라·초록·분홍·겨자·파랑의 낮은 채도 7색을 서비스 구분에 사용합니다.
- 유리 효과는 내비게이션과 작은 위젯 표면에만 적용합니다.
- 상태는 색과 함께 이름, 백분율, 문장으로 표시합니다.

## 확인 방법

```powershell
npm run dev
```

- 데스크톱 기준: `http://127.0.0.1:4173/?variant=A`
- 모바일 기준: `http://127.0.0.1:4173/?variant=C`를 390×844 크기로 확인
- 기준선 무결성: `npm run verify:baseline`
- 토큰 무결성: `npm run verify:tokens`

## 변경 규칙

기준 디자인을 의도적으로 바꿀 때만 스크린샷과 `baseline.json`의 해시를 함께 갱신합니다. 단순 구현 과정에서는 이 기준선을 고치지 않고, 제품 코드가 기준선에 맞는지 비교합니다.

토큰을 바꿀 때는 `npm run verify:tokens`와 브라우저 A/C 회귀 확인을 함께 실행합니다.
