# SPECTRA v0.3.5 — 계정 연결과 미리보기 보안 수정

## 변경 사항

- 계정 창의 새로고침은 사용량만 다시 확인합니다. 로그인과 사용량 브리지 설치는 해당 버튼을 눌렀을 때만 시작합니다. 조회 도중 계정 상태가 바뀌어도 선택한 동작을 유지합니다.
- 개발용 정적 미리보기는 A·B·C 시안에 필요한 파일만 제공합니다. 목록 밖의 저장소 파일은 요청할 수 없습니다.
- v0.3.4 이후에 반영한 Claude Fable 주간 한도와 macOS의 Focus Dock·메뉴 막대 및 Claude Keychain 연동 개선이 포함됩니다.

## 설치 및 업데이트

- Windows에서는 앱의 자동 업데이트 안내를 이용하거나 `SPECTRA_0.3.5_x64-setup.exe`를 내려받아 설치할 수 있습니다.
- macOS 설치 파일은 Actions 빌드에서 Apple Silicon과 Intel용으로 각각 제공합니다. 설치 방법과 서명 범위는 [macOS 안내](https://github.com/newskool4d-sketch/spectra-ai-usage-widget/blob/main/docs/macos.md)를 참고하세요.
- 선택 설치형 작업표시줄 유지 모듈의 기존 공개 ZIP은 신규 설치 시 v0.3.4까지 지원합니다.
