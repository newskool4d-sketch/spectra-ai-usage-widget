# SPECTRA v0.2.8

로그인된 상태에서도 작업표시줄과 창의 Claude·Codex 사용량이 몇 분씩 사라지던 문제를 수정했습니다.

## 변경사항

- Claude Code 자격 증명에 구독 로그인이 있으면 2분마다 `claude auth status`를 실행하지 않고 사용량을 바로 조회합니다. 부하가 높을 때 이 명령이 5초 제한을 넘기면 값이 지워지던 원인을 없앴습니다.
- `claude auth status`는 로그인 정보를 읽지 못했거나 사용량 조회가 401·403으로 거부될 때만 실행하며, 제한 시간은 15초입니다.
- Claude Code나 Codex App Server의 일시적인 조회 실패에는 마지막으로 확인한 값을 `갱신 대기 (캐시)`로 계속 표시합니다. 작업표시줄, 트레이 배지, 창이 같은 값을 보여 주고 실패 후 재시도 간격은 기존처럼 늘어납니다.
- 이어서 표시하는 값 중 초기화 시각이 지난 창은 초기화 전 수치 대신 `—`로 표시합니다. 작업표시줄, 트레이 배지, 미니 창에 적용됩니다.
- 이전 값이 없을 때의 조회 실패는 `연결 상태 확인 필요` 대신 `사용량 확인 지연`으로 표시합니다. 이어서 표시하는 Codex 값의 툴팁에도 마지막 동기화 시각을 보여 줍니다.

## 알려진 제한

- 로그아웃, 미설치, API 키 로그인처럼 계정 상태가 달라진 경우에는 이전 값을 유지하지 않고 해당 안내를 표시합니다.
- 대시보드의 서비스 목록과 집중 확인 카드는 초기화 시각이 지난 이어받은 값을 아직 수치로 표시합니다.
- 트레이 배지는 다음 조회 때 초기화 경계를 반영합니다.

## 설치 및 업데이트

기존 설치본은 앱의 새 버전 안내에서 **지금 설치**를 선택하세요. 새 설치는 이 release의 `SPECTRA_0.2.8_x64-setup.exe`를 사용합니다. `SHA256SUMS.txt`로 공개 자산의 해시를 대조할 수 있습니다.
