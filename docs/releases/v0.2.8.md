# SPECTRA v0.2.8

로그인된 상태에서도 작업표시줄과 창의 Claude·Codex 사용량이 몇 분씩 사라지던 문제를 수정했습니다.

## 변경사항

- Claude Code 자격 증명에 구독 로그인이 있으면 2분마다 `claude auth status`를 실행하지 않고 사용량을 바로 조회합니다. 부하가 높을 때 이 명령이 5초 제한을 넘기면 값이 지워지던 원인을 없앴습니다.
- `claude auth status`는 로그인 정보를 읽지 못했거나 사용량 조회가 401·403으로 거부될 때만 실행하며, 제한 시간은 15초입니다.
- Claude Code나 Codex App Server의 조회가 일시적으로 실패해도 마지막으로 확인한 값을 계속 표시하고, 갱신을 기다리는 상태임을 함께 알립니다. 작업표시줄, 트레이 배지, 창이 같은 값을 보여 주고 실패 후 재시도 간격은 기존처럼 늘어납니다.
- 이어서 표시하는 값 중 초기화 시각이 지난 창은 초기화 전 수치 대신 `—`로 표시합니다. 작업표시줄, 트레이 배지, 미니 창과 대시보드 개요의 한도 칸에 적용됩니다.
- 이전 값이 없을 때의 조회 실패는 `연결 상태 확인 필요` 대신 `사용량 확인 지연`으로 표시합니다. 이어서 표시하는 Codex 값의 툴팁에도 마지막 동기화 시각을 보여 줍니다.

## 알려진 제한

- 로그아웃, 미설치, API 키 로그인처럼 계정 상태가 달라진 경우에는 이전 값을 유지하지 않고 해당 안내를 표시합니다.
- 대시보드의 서비스 목록, 서비스 칩, 집중 확인 카드는 초기화 시각이 지난 이어받은 값을 아직 수치로 표시합니다.
- 트레이 배지는 다음 조회 때 초기화 경계를 반영합니다.

## 설치 및 업데이트

기존 설치본은 앱의 새 버전 안내에서 **지금 설치**를 선택하세요. 새 설치는 이 release의 `SPECTRA_0.2.8_x64-setup.exe`를 사용합니다. `SHA256SUMS.txt`로 공개 자산의 해시를 대조할 수 있습니다.

## 작업표시줄 유지 모듈 추가 배포 — 2026-10-10

볼륨·빠른 설정 메뉴를 닫은 뒤 숫자가 계속 보이도록 확인된 외부 유지 모듈을 추가합니다. `SPECTRA_0.2.8_taskbar-keeper.zip`에 모듈과 Windows 로그인 자동 실행 설치 스크립트를 담았습니다. 압축 안의 `README.md`를 따라 적용할 수 있습니다. 이미 이 모듈을 적용한 PC는 다시 설치할 필요가 없습니다.

기존 v0.2.8 앱, 설치 파일과 자동 업데이트 manifest는 그대로 유지합니다. 추가 모듈은 자동 업데이트로 설치되지 않으며 PowerShell 7이 필요합니다. ZIP의 해시는 별도 `.sha256` 파일로 확인할 수 있습니다.

현재 PC의 실제 메뉴 동작과 자동 실행 작업은 확인했습니다. 실제 재부팅과 다른 PC 새 설치는 아직 검증하지 않았습니다.
