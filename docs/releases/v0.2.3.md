# SPECTRA v0.2.3

작업 표시줄 스트립의 실제 마우스 hover 표시를 확인하고, 다음 릴리즈부터 서명·자산 검증·체크섬 업로드·공개 전환을 GitHub Actions에서 자동 수행합니다.

## 변경사항

- 작업 표시줄 스트립 툴팁의 실제 마우스 hover 표시 확인
- Claude 사용량의 최신성 상태와 실제 데이터 수집 시각 표시
- GitHub Actions 릴리즈 파이프라인의 초안 자산 검증 및 자동 공개 경로 적용

## 설치 및 업데이트

기존 설치본은 앱 내 업데이트 알림에서 `지금 설치`를 선택하세요. 새 설치는 아래 릴리즈의 `SPECTRA_0.2.3_x64-setup.exe`를 사용하면 됩니다.
