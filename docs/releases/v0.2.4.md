# SPECTRA v0.2.4

작업 표시줄 표시를 켜 두면 Codex·Claude 잔여량이 2분마다 스스로 갱신되고, Claude Code가 로그인 토큰을 새로 받으면 곧바로 반영됩니다.

## 변경사항

- 작업 표시줄 표시가 켜진 동안 네이티브 루프가 Claude → Codex 순으로 2분마다 사용량을 다시 확인합니다. 표시가 꺼져 있으면 이전과 같이 조회하지 않습니다.
- Claude Code가 `.credentials.json`을 다시 쓰면(세션 시작 등으로 토큰이 갱신되면) 다음 확인 주기를 기다리지 않고 15초 안에 Claude를 다시 조회합니다.
- 조회 실패는 2분·4분·8분·16분·30분으로 간격을 늘리고, Claude 토큰이 만료된 동안에는 자격 증명이 바뀌거나 30분이 지날 때까지 조회하지 않습니다. 이전의 60초 재시도 반복을 없앴습니다.
- Claude 토큰 만료 상태를 창과 작업 표시줄 툴팁에서 `로그인 갱신 필요`로 표시합니다. Claude Code를 한 번 실행하면 자동으로 복구됩니다.
- 네이티브 루프가 받은 최신 값이 열려 있는 창에도 즉시 반영되어 창과 작업 표시줄이 같은 수치를 보여 줍니다. 창의 조회 시도 표시는 `자동 확인 HH:MM`으로 나타납니다.

## 설치 및 업데이트

기존 설치본은 앱 내 업데이트 알림에서 `지금 설치`를 선택하세요. 새 설치는 아래 릴리즈의 `SPECTRA_0.2.4_x64-setup.exe`를 사용하면 됩니다. `SHA256SUMS.txt`로 파일 해시를 대조할 수 있습니다.
