# SPECTRA v0.3.2 — 작업표시줄 AG Gemini 기준 표시와 갱신 안내 완화

작업표시줄의 AG 값을 Gemini 모델군 기준으로 바꾸고, Claude·Antigravity의 갱신 필요 안내가 자주 뜨던 원인을 고쳤습니다. 테스트·실화면·공개·설치의 확인 범위는 [v0.3.2 검증 기록](https://github.com/newskool4d-sketch/spectra-ai-usage-widget/blob/main/docs/release-0.3.2-qa.md)에 구분합니다.

## 변경사항

- 작업표시줄 AG 값은 **Gemini 모델군의 5시간·주간 중 낮은 잔여율**을 표시합니다. Gemini 4 Argon과 Claude·GPT는 툴팁에서 계속 확인할 수 있습니다. Gemini 값이 없으면 다른 모델군으로 대체하지 않고 `—`로 표시합니다.
- Antigravity 값은 수집 5분 뒤가 아니라 **초기화 시각이 지나거나 수집 후 24시간이 지났을 때** 갱신 필요로 표시합니다. 툴팁의 마지막 CLI 수집 시각으로 값의 나이를 확인할 수 있습니다.
- Claude 토큰 갱신이 실패해도 30분 동안 조회를 멈추지 않고 2분부터 다시 시도합니다(최대 30분 간격). 절전 해제 직후 네트워크가 준비되기 전에 갱신이 실패한 경우 자동으로 복구됩니다.
- 선택 설치형 작업표시줄 유지 모듈의 지원 버전에 v0.3.2를 추가합니다.

## 사용 범위

Antigravity 사용량은 지금도 공식 CLI 상태선에서만 전달됩니다. CLI를 실행하지 않으면 수치는 새로 들어오지 않으며, GUI만 사용한 사용량은 다음 CLI 실행 전까지 반영되지 않습니다.

트레이 배지의 최소 잔여 값은 이번 변경 범위가 아니며, Antigravity의 모든 모델군을 계속 포함합니다.

## Windows 설치

Windows 설치 파일명은 `SPECTRA_0.3.2_x64-setup.exe`입니다. 공개 자산의 업데이터 서명·manifest·해시와 정식 설치본의 확인 결과는 위 검증 기록에 구분해 기록합니다.
