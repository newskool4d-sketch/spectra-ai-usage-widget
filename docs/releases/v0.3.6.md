# SPECTRA v0.3.6 — Windows 작업표시줄 복구

## 변경 사항

- Explorer의 작업표시줄 창을 잠시 찾을 수 없을 때 기존 연결을 유지하고, 새 창이 생기면 사용량 표시를 다시 연결합니다.
- 빠른 설정을 닫는 과정 등에서 작업표시줄이 사용량 표시를 가리는 상황에 복구 타이머를 사용합니다. 복구할 때 다른 팝업의 순서와 입력 포커스를 보존하도록 했습니다.
- Windows에서 임시 창으로 연결과 표시 복구를 검증했습니다. 실제 Explorer 재시작과 설치본의 동작은 별도 확인이 필요합니다. [변경 및 검사 결과](https://github.com/newskool4d-sketch/spectra-ai-usage-widget/pull/12)

## 설치 및 업데이트

- Windows에서는 앱의 자동 업데이트 안내를 이용하거나 `SPECTRA_0.3.6_x64-setup.exe`를 내려받아 설치할 수 있습니다.
- macOS 설치 파일은 Apple Silicon과 Intel용으로 Actions에 제공합니다. [macOS 설치 안내](https://github.com/newskool4d-sketch/spectra-ai-usage-widget/blob/main/docs/macos.md)
