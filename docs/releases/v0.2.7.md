# SPECTRA v0.2.7

사용량 조회가 멈추는 시간 제한 경로와 업데이트 실패 후 복구를 수정했습니다.

## 변경사항

- 공급자 명령의 stdin 전송·stdout 수집·프로세스 종료 대기에 하나의 시간 제한을 적용해, 읽지 않는 입력이나 상속된 출력 파이프 때문에 조회가 계속 기다리는 문제를 수정했습니다.
- 대기 화면에서 복원한 Codex 데이터가 120초 이상 지났거나 리셋 시각을 넘었으면 다시 조회합니다. 오류·빈 데이터·잘못된 수집 시각도 재조회합니다.
- 주간 또는 5시간 한도가 소진된 서비스는 작업 추천에서 제외합니다. 리셋 시각 경과는 화면에서도 15초 주기로 다시 판단합니다.
- 업데이트 확인에 15초, 다운로드에 120초 네트워크 제한을 적용했습니다. 확인·설치 중 중복 요청을 막고 실패 후 오류 안내와 다시 확인 버튼을 유지합니다. 다운로드 제한은 설치 프로그램 전체 실행 시간 제한이 아닙니다.
- 작업표시줄 스트립이 알림 영역과 겹칠 정도로 공간이 좁으면 숨기고 공간이 돌아오면 복원합니다. 셸 위치 변경과 대상 작업표시줄의 DPI를 반영합니다.

## 검증 범위

Windows 네이티브·GDI 테스트, 로컬 서버를 이용한 실제 HTTP 시간 제한·재시도, 실제 Windows 실행 파일의 공급자 조회를 검증했습니다. 업데이트 실패 후 화면 복구와 중복 클릭 방지는 실제 App에 모의 응답을 연결한 브라우저에서 확인했습니다.

물리적인 다중 모니터 전환, 실제 설치 프로그램 실패 후 복구, Unix 실구동은 미검증입니다. 업데이터 서명은 Windows 게시자 인증과 별개입니다.

## 설치 및 업데이트

기존 설치본은 앱의 새 버전 안내에서 **지금 설치**를 선택하세요. 새 설치는 이 release의 `SPECTRA_0.2.7_x64-setup.exe`를 사용합니다. `SHA256SUMS.txt`로 공개 자산의 해시를 대조할 수 있습니다.
