# SPECTRA v0.3.0 — Focus Dock

선택한 서비스와 모델군의 구독 한도를 한눈에 확인하는 포커스 도크를 제공합니다. 미니창 다크·라이트, 기간별 실제 수집 이력, Antigravity 공식 CLI 상태선 연결을 추가했습니다. 검사·배포·설치의 확인 범위는 [v0.3.0 검증 기록](https://github.com/newskool4d-sketch/spectra-ai-usage-widget/blob/main/docs/release-0.3.0-qa.md)에 구분해 기록합니다.

## 변경사항

- 대시보드와 미니창을 선택한 서비스·모델군의 잔여량에 집중하는 포커스 도크로 정리합니다.
- 미니창 상단에서 다크·라이트 모드를 전환하고, 선택한 테마를 재실행 후에도 유지합니다.
- 설정 버튼을 첫 화면에서 접근할 수 있도록 배치하고, 미니창에서 대시보드를 열거나 창 고정을 바꿀 수 있도록 연결합니다.
- 기존 비용 탭을 **구독 모델**로 바꿔 연결된 요금제와 모델군·한도 정보를 표시합니다. 잔여율을 금액으로 환산하지 않습니다.
- 실제 수집한 한도 수치를 로컬에 최대 31일 보관하고 오늘·최근 7일·최근 30일로 조회합니다. 기록이 없는 과거 날짜는 빈 기간으로 표시합니다.
- Antigravity CLI의 공식 상태선 연동을 추가합니다. 구독 등급과 모델군별 한도를 읽고, Antigravity 안의 Claude·GPT 모델군을 Claude 직접 구독과 구분합니다.
- 기존 개선 브랜치의 Claude 인증 갱신 및 작업표시줄 유지 모듈 검증 개선을 포함합니다.

## Antigravity 연결 안내

Antigravity CLI에서 로그인한 뒤 SPECTRA 설정에서 상태선 연결을 설치하고 CLI를 실행해야 첫 수치가 들어옵니다. 이후 CLI가 상태선 정보를 보낼 때 사용량이 갱신됩니다. Antigravity GUI만 실행한 상태의 자동 갱신은 지원하지 않습니다.

SPECTRA는 상태선 입력에서 구독 등급·한도 등 필요한 필드만 추립니다. 이메일, 작업 제목, 경로, 인증정보와 원본 입력 전문을 사용량 기록에 저장하지 않습니다. 조회가 늦거나 초기화 시각이 지난 수치는 최신 값과 구분해 표시합니다.

## Windows 설치

Windows 설치 파일은 `SPECTRA_0.3.0_x64-setup.exe`입니다. 공개 자산의 업데이터 서명·manifest·SHA-256과 로컬 설치·실행을 확인했습니다. 정식 설치본에서 Antigravity 연결, 기간 조회, 설정, 다크·라이트 전환 및 재실행 후 테마 유지를 검증했습니다. Windows Authenticode 게시자 코드 서명은 없으며, 이는 검증된 업데이터 서명과 별개입니다.
