# SPECTRA v0.3.1 — 작업표시줄 Antigravity 표시

Windows 작업표시줄에 Antigravity를 추가해 Codex·Claude와 함께 남은 한도를 확인할 수 있습니다. 모델군별 툴팁과 좁은 폭의 요약 표시도 개선했습니다. 테스트·실화면·공개·설치의 확인 범위는 [v0.3.1 검증 기록](https://github.com/newskool4d-sketch/spectra-ai-usage-widget/blob/main/docs/release-0.3.1-qa.md)에 구분합니다.

## 변경사항

- Windows 작업표시줄에서 기존 Codex·Claude와 함께 Antigravity의 남은 한도를 확인할 수 있도록 개선합니다.
- Antigravity 모델군의 유효한 한도 창 중 **잔여 비율이 가장 낮은 한도**를 요약하고, 툴팁에서는 모델군별 정보를 구분합니다.
- 공식 CLI 수집이 늦거나 오래된 경우 최신 데이터와 구분하고, 좁은 작업표시줄 공간에서도 요약과 상세 정보를 확인할 수 있도록 배치를 조정합니다.
- 선택 설치형 작업표시줄 유지 모듈의 지원 버전에 v0.3.1을 추가합니다. 기존 v0.3.0 지원과 설치 구성을 보존합니다.

## 사용 범위

Antigravity 사용량은 v0.3.0과 동일하게 공식 CLI 상태선 연결에서 전달됩니다. GUI만 실행한 상태의 자동 수집은 지원하지 않으며, 새로운 수치를 받으려면 CLI가 상태선을 실행해야 합니다. 작업표시줄 추가가 새로운 인증정보 접근이나 GUI 직접 조회를 뜻하지 않습니다.

포커스 도크, 구독 모델 화면, 다크·라이트, 실제 수집 이력의 오늘·7일·30일 조회는 v0.3.0에서 제공한 기능을 유지합니다.

## Windows 설치

Windows 설치 파일명은 `SPECTRA_0.3.1_x64-setup.exe`입니다. 공개 자산의 업데이터 서명·manifest·해시와 정식 설치본의 확인 결과는 위 검증 기록에 구분해 기록합니다.
