# SPECTRA v0.3.7 — 시작 메뉴를 연 뒤 사라지는 작업표시줄 표시 수정

## 변경 사항

- v0.3.6에서 시작 메뉴를 한 번 열면 작업표시줄의 사용량 표시가 사라지고 앱을 다시 시작할 때까지 돌아오지 않던 문제를 고쳤습니다.
- 시작 메뉴가 열려 있는 동안 Windows는 작업표시줄을 다른 표시 층으로 옮기고, 그동안 사용량 표시의 연결 상태를 확인할 수 없게 합니다. v0.3.6은 이를 연결이 끊긴 것으로 보고 다시 연결하다가 표시를 잃었습니다. 이제 이미 연결한 작업표시줄이 그대로 있으면 다시 연결하지 않습니다.
- Windows 11(빌드 26300)의 실제 작업표시줄에서 시작 메뉴를 여러 번 열고 닫아 표시가 유지되는 것을 확인했습니다. 빠른 설정·알림 센터·검색 창과 Explorer 재시작은 별도 확인이 필요합니다. [변경 및 검사 결과](https://github.com/newskool4d-sketch/spectra-ai-usage-widget/pull/13)

## 설치 및 업데이트

- Windows에서는 앱의 자동 업데이트 안내를 이용하거나 `SPECTRA_0.3.7_x64-setup.exe`를 내려받아 설치할 수 있습니다.
- macOS 설치 파일은 Apple Silicon과 Intel용으로 Actions에 제공합니다. [macOS 설치 안내](https://github.com/newskool4d-sketch/spectra-ai-usage-widget/blob/main/docs/macos.md)
