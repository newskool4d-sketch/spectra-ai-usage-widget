# SPECTRA v0.2.2

- GitHub Release 기반 자동 업데이트를 연결했습니다. 미니 창 또는 대시보드를 열면 새 버전을 확인하고, 사용자가 `지금 설치`를 선택하면 업데이트합니다.
- Claude 작업표시줄 툴팁에 데이터 최신성, 마지막 동기화, 갱신 대기 및 로그인 필요 상태를 구분해 표시합니다.
- Claude 초기화 이후 사용량 재확인과 더 굵고 큰 작업표시줄 글씨를 포함합니다.

## 설치 및 업데이트

기존 **공개 v0.2.1**에는 자동 업데이트 기능이 없습니다. 이 경우 아래의 `SPECTRA_0.2.2_x64-setup.exe`로 한 번 수동 설치하세요. 이후 릴리즈부터 앱 안에서 업데이트할 수 있습니다. 자동 업데이트 기능을 넣어 별도로 재빌드한 로컬 v0.2.1은 이번 버전으로 앱 내 업데이트가 가능합니다.

설치 파일과 `SHA256SUMS.txt`를 대조할 수 있습니다. `.exe.sig`는 Tauri 업데이트 검증용 서명이며 Windows Authenticode 서명과는 다릅니다. 현재 Windows 게시자 인증서는 없으므로 SmartScreen 경고가 나타날 수 있습니다.

창이 없는 상태의 정기 업데이트 확인과 Windows 알림, 다운로드 진행률, 글자 크기 설정은 이번 버전에 포함하지 않았습니다.
