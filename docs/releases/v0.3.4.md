# SPECTRA v0.3.4 — 대시보드 Antigravity 모델군 순서 고정

대시보드에서 Antigravity 모델군이 나오는 순서를 고정했습니다. 테스트·공개·설치의 확인 범위는 [v0.3.4 검증 기록](https://github.com/newskool4d-sketch/spectra-ai-usage-widget/blob/main/docs/release-0.3.4-qa.md)에 구분합니다.

## 변경사항

- 대시보드의 Antigravity 모델군을 **Gemini → Gemini 4 Argon → Claude · GPT** 순으로 표시합니다. 이전에는 수집 데이터가 도착한 순서를 그대로 써서 순서가 일정하지 않았습니다.
- 모델군 탭과 선택 목록, "다른 모델군", 구독 모델 패널에 같은 순서를 적용합니다. 알려지지 않은 모델군은 수집 순서대로 뒤에 둡니다.
- 처음 선택되는 모델군(잔여율이 가장 낮은 창의 모델군)과 작업표시줄·트레이의 AG 계산 기준(Gemini 모델군)은 v0.3.3과 같습니다.
- 선택 설치형 작업표시줄 유지 모듈의 지원 버전에 v0.3.4를 추가합니다.

## 사용 범위

Antigravity 사용량은 지금도 공식 CLI 상태선에서만 전달됩니다. 이번 변경은 표시 순서만 바꾸며 수집·계산 값은 바꾸지 않습니다.

## Windows 설치

Windows 설치 파일명은 `SPECTRA_0.3.4_x64-setup.exe`입니다. 공개 자산의 업데이터 서명·manifest·해시와 정식 설치본의 확인 결과는 위 검증 기록에 구분해 기록합니다.
