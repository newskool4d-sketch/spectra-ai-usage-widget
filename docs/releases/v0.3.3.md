# SPECTRA v0.3.3 — 트레이 배지 AG Gemini 기준 표시

트레이 배지의 Antigravity 계산을 v0.3.2의 작업표시줄과 같은 Gemini 기준으로 맞췄습니다. 테스트·공개·설치의 확인 범위는 [v0.3.3 검증 기록](https://github.com/newskool4d-sketch/spectra-ai-usage-widget/blob/main/docs/release-0.3.3-qa.md)에 구분합니다.

## 변경사항

- 트레이 배지와 트레이 툴팁의 최소 잔여 값을 계산할 때 Antigravity는 **Gemini 모델군의 5시간·주간 중 낮은 잔여율**만 사용합니다. Gemini 4 Argon과 Claude·GPT는 계산에 넣지 않습니다.
- Antigravity에 Gemini 값이 없으면 다른 모델군으로 대체하지 않고 계산에서 제외합니다. 다른 서비스의 값이 있으면 그 값을 표시합니다.
- 선택 설치형 작업표시줄 유지 모듈의 지원 버전에 v0.3.3을 추가합니다.

## 사용 범위

트레이 배지는 지금처럼 연결된 서비스 중 가장 낮은 값을 하나만 표시합니다. 다른 서비스의 잔여율이 더 낮으면 Antigravity 대신 그 서비스가 표시됩니다.

Antigravity 사용량은 지금도 공식 CLI 상태선에서만 전달됩니다.

## Windows 설치

Windows 설치 파일명은 `SPECTRA_0.3.3_x64-setup.exe`입니다. 공개 자산의 업데이터 서명·manifest·해시와 정식 설치본의 확인 결과는 위 검증 기록에 구분해 기록합니다.
