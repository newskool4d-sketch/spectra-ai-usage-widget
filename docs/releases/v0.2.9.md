# SPECTRA v0.2.9

앱 동작 변경이 없는 문서·배포물 정리 릴리스입니다. 설치 파일은 v0.2.8과 같은 소스 코드를 다시 빌드한 것입니다.

## 변경사항

- 2026-10-29 정기 점검 보고 `docs/inspection-2026-10-29.md`를 추가했습니다. 테스트·검증 게이트·의존성·설치본·작업표시줄 유지 모듈·공급자 연결·공개 릴리스·문서 정합 점검 결과와 후속 개선 항목 F1~F10을 담았습니다.
- v0.2.8 작업표시줄 유지 모듈 스크립트(`scripts/taskbar-keeper/`)와 배포 검증 기록을 소스에 포함했고, Windows 체크아웃에서도 스크립트 체크섬이 보존되도록 줄바꿈 속성을 고정했습니다.
- v0.2.8 공개 배포 검증 기록을 추가했습니다.

## 알려진 제한

- 앱 기능·수정 사항은 v0.2.8과 같습니다. 유지 모듈이 로그온 뒤 외부 종료되면 다시 시작되지 않는 문제와, 유지 모듈 설치 스크립트가 v0.2.8 로컬 빌드 실행 파일 해시에만 적용되는 문제는 아직 해결하지 않았습니다(점검 보고 F1·F2). 유지 모듈 추가 설치는 v0.2.8 릴리스의 `SPECTRA_0.2.8_taskbar-keeper.zip`을 사용하며, v0.2.9 설치 파일에는 적용되지 않습니다.
- 이미 유지 모듈을 적용한 PC는 v0.2.9로 업데이트해도 유지 모듈이 설치된 앱 경로를 그대로 사용하므로 다시 설치할 필요가 없습니다.
- 작업표시줄 표시가 켜진 상태의 Claude 자동 갱신 간격이 설계값 2분보다 길게 관측된 건은 원인 확인 중입니다(점검 보고 F3).

## 설치 및 업데이트

기존 설치본은 앱의 새 버전 안내에서 **지금 설치**를 선택하세요. 새 설치는 이 release의 `SPECTRA_0.2.9_x64-setup.exe`를 사용합니다. `SHA256SUMS.txt`로 공개 자산의 해시를 대조할 수 있습니다. Windows Authenticode 서명은 없으므로 SmartScreen 경고가 표시될 수 있습니다.
