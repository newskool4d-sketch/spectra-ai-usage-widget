# Focus Dock 구현 범위와 완료 기준

확인일: 2026-11-02
대상: SPECTRA Windows v0.3.0
상태: PASS — 구현·테스트 220건·독립 검토·v0.3.0 공개 릴리즈 및 자산 검증·로컬 설치·정식 설치본 핵심 화면·Antigravity 실제 전달·재실행 후 테마 유지 확인 완료.

검증 상태의 정본: [v0.3.0 검증 기록](release-0.3.0-qa.md). 이 문서는 구현 계약이며, 완료 판정은 승인 시안이나 코드 존재가 아닌 실제 검사·공개 자산·정식 설치본 실행 증거에 근거합니다.

## 사용자 결정

- 대시보드·미니창 디자인은 포커스 도크를 기준으로 합니다.
- 미니창에 다크·라이트 전환을 추가하고 선택을 유지합니다.
- 비용은 의미가 크지 않다는 사용자 의견에 따라 **구독 모델** 화면으로 대체합니다.
- 수정 후 커밋·푸시·릴리즈·로컬 설치 및 확인까지 수행합니다.

## 디자인 기준

- `docs/design-baseline/focus-dock-approved.png`: 대시보드와 미니창 구성.
- `docs/design-baseline/focus-dock-mini-themes-approved.png`: 미니창 다크·라이트 상태.
- 위 이미지는 예시 수치를 포함한 승인 시안입니다. 실제 앱 렌더링·계정 연결·기간 조회의 증거로 사용하지 않습니다.
- 과거 A/C 시안 파일은 이력 참조용으로 보존합니다. 현재 제품은 하나의 미니창 또는 대시보드를 선택해서 렌더링하며 좁은 화면은 CSS로 대응합니다.
- 서비스 이름·한도 창 이름·숫자를 명시해 색상만으로 의미를 구분하지 않습니다.

## 기능 계약

| 요구사항 | 구현 계약 | 완료에 필요한 증거 |
|---|---|---|
| 대시보드 | 서비스 선택, 모델군 선택, 큰 잔여량, 다른 한도·모델군 요약 | 실제 렌더링 및 선택 동작 |
| 미니창 | 서비스 탭, 모델 선택, 잔여량, 설정·새로고침·테마·고정·대시보드 열기 | 설치본의 버튼별 동작 |
| 다크·라이트 | 같은 정보 배치, 두 테마의 대비, native 설정 저장 | 테마 전환 후 앱 재실행 |
| 구독 모델 | 연결 요금제·모델군·한도 정보; 추정 청구액 제거 | 탭 선택 시 내용 변경 |
| 기간 조회 | 실제 수집 시각 기준 오늘·7일·30일 필터 | 경계값 테스트와 실제 화면 |
| 기록 저장 | 정제된 숫자만 최대 31일·32,000개, 15분 구간 중복 제한, 원자적 저장 | 저장·복구·보존기간 테스트 |
| Antigravity | 공식 CLI statusLine 입력에서 quota/plan만 추출 | 비식별 fixture와 실제 CLI 전달 |
| 연결 경계 | 직접 Claude 구독과 Antigravity Claude·GPT 구분; 연결 전·오래된 데이터 명시 | 각 연결 상태 렌더링 |
| 릴리즈 | 버전 정합성, 빌드, 공개 자산·서명·해시, 설치본 일치 | 릴리즈 증거표 |

## 데이터와 연결 제한

Antigravity 사용량은 공식 CLI 상태선에서 전달됩니다. GUI만 실행한 경우에는 갱신되지 않습니다. 상태선 연결을 설치한 뒤 CLI가 한 번 이상 정보를 전달해야 첫 수치가 나타납니다. 입력 전문·계정 식별정보·작업 내용·인증정보는 저장하지 않습니다.

기간 이력은 SPECTRA가 실제로 수집한 시점부터 시작합니다. 이전 30일을 복원한 것으로 표시하지 않으며, 결측을 0이나 예시 곡선으로 채우지 않습니다. 수집 횟수를 AI 요청 횟수로 해석하지 않습니다.

## 검증 단계

1. 버전·디자인 기준·토큰·번들 예산 검사.
2. 프런트엔드 및 네이티브 단위 테스트, production 빌드.
3. 대시보드·미니창 두 테마와 설정·구독 모델·기간 전환 실화면 점검.
4. 공개 릴리즈 자산·업데이터 서명·해시·소스 리비전 확인.
5. 설치본 버전·해시·실행 및 핵심 동작 확인.

완료 여부는 각 단계의 실제 결과를 모은 릴리즈 증거표에서 판정합니다. 기존부터 실패하던 검사도 이유 없이 통과 처리하거나 예산을 늘리지 않습니다.
